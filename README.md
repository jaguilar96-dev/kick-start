# MVP web comercial - Servicios Administrativos de Clinicas Especializadas

Este proyecto contiene tres propuestas visuales independientes para una web comercial de afiliacion, consulta de clinicas y centros especializados, planes, beneficios y contacto.

## Propuesta 1

Carpeta: `propuesta1/`

- Paleta principal obligatoria: celeste `#00bace`, celeste fuerte `#0094a6` y gris oscuro `#383838`.
- Enfoque visual: medico corporativo, limpio, confiable, con mucho blanco, botones celestes, tarjetas suaves y bordes redondeados.

## Propuesta 2

Carpeta: `propuesta2/`

- Paleta: azul petroleo, verde agua, blanco calido y gris grafito.
- Enfoque visual: healthtech moderna, con formas organicas, gradientes suaves, sombras e interacciones mas dinamicas.

## Propuesta 3

Carpeta: `propuesta3/`

- Paleta: azul profundo, gris oscuro, blanco y acentos celestes.
- Enfoque visual: premium e institucional, ideal para empresas y convenios corporativos.

## Como abrir

Cada propuesta funciona como HTML estatico. Puedes abrir localmente cualquiera de estos archivos con doble clic:

- `propuesta1/index.html`
- `propuesta2/index.html`
- `propuesta3/index.html`

Todas las paginas internas estan enlazadas desde el menu principal y el footer.

## Paginas incluidas por propuesta

- `index.html`
- `quienes-somos.html`
- `atiendete-aqui.html`
- `planes.html`
- `contacto.html`
- `servicios.html`
- `beneficios.html`
- `login.html`

## Interacciones implementadas

- Menu hamburguesa responsive.
- Cambio visual del header al hacer scroll.
- Filtro de clinicas por nombre, departamento y especialidad con JavaScript vanilla.
- Tabs de planes para Persona natural y Empresa.
- Validacion frontend del formulario de contacto.
- Mensaje visual de exito al enviar el formulario.
- Scroll suave para enlaces internos.
- Boton flotante de WhatsApp de ejemplo.
